Connect to Whisper AI

SubForge uses OpenAI's Whisper model hosted on HuggingFace for transcription. You'll need a free API key to get started:

  1. 1 Go to huggingface.co/settings/tokens and create a free account
  2. 2 Click "Create new token", give it any name, and select "Read" access
  3. 3 Copy the token (starts with hf_) and paste it below

Your key is stored locally in your browser. It is never sent anywhere except HuggingFace.
